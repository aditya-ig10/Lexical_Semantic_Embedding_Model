How it works

The pipeline, step by step.

Tokens go in, meaning vectors come out. Pick a similarity head to see when it wins.

Core idea

BiLSTM reads both ways, attention decides what matters

Embedding (300-d, plus positional) → 2-layer BiLSTM (512 hidden) → 8-head self-attention with residual + LayerNorm → mean/max pooling → similarity head → tanh/sigmoid score.

cosine: angle between vectors. Best default for paraphrase and STS; immune to length.

Quickstart

From zero to scores in a few commands.

docker — cpu setup
docker-compose up lexical-dev
# Jupyter Lab → http://localhost:8888
python scripts/data_download.py --datasets all --output-dir data/raw
python scripts/preprocess.py --datasets sts-benchmark sick quora mrpc
python scripts/train.py --config config/train_config.py --model-config medium
python scripts/evaluate.py --model-path models/best_model.pt --datasets sts-benchmark sick
